Môn học: Lập trình Web (CSE391)

📖 Giới thiệu
CSE391 – Web Programming là môn học cung cấp kiến thức nền tảng và thực hành về web.

Môn học giúp sinh viên làm quen với cách xây dựng website từ cơ bản đến nâng cao, đồng thời rèn luyện tư duy lập trình web và kỹ năng làm việc với các công cụ phát triển hiện đại.

🧠 Nội dung chính

HTML5, CSS3

JavaScript cơ bản

Thiết kế giao diện đáp ứng (Responsive Web Design)

Sử dụng Git & GitHub để quản lý mã nguồn

Framework và thư viện hỗ trợ (Bootstrap, v.v.)

Kiến thức cơ bản về Web Server và Backend

🎯 Mục tiêu môn học

Hiểu cấu trúc và nguyên lý hoạt động của một website

Xây dựng được giao diện web hoàn chỉnh

Biết cách quản lý và làm việc nhóm với Git/GitHub

Rèn luyện tư duy và kỹ năng lập trình web thực tế

📂 Nội dung Repository

📁 html/ – Các bài tập và thực hành HTML
📁 css/ – Styling, layout và thiết kế giao diện
📁 js/ – Các bài tập JavaScript
📁 assets/ – Hình ảnh và tài nguyên sử dụng trong dự án
📁 result/ – Kết quả sau khi hoàn thành bài thực hành
📄 README.md – File giới thiệu repository
